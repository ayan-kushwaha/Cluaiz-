# Component: inference-cel

## Technical Specification
- **Purpose:** Universal AST parser and orchestrator that parses CEL scripts into a deterministic execution plan, transpiles payloads to Bincode/CXP, and dynamically routes them to WASM or Native C-FFI sandboxes.
- **Platform Support:** Cross-platform (Windows, Linux, macOS)
- **Reusability Level:** High (Global Core Router for all LLM plugin requests)

## API Contract (Interface)
- **Props/Struct/Trait:** `IntegrationMetadata`, `CelPlanner`, `Transpiler`
- **Export Type:** Public Module (`parser`, `ffi`, `execution`)
- **Dependencies:** `wasmtime`, `libloading`, `bincode`, `serde`

## Failure & Recovery Logic
- **Potential Failure Point:** The `ast.rs` parser fails to parse malformed CEL output generated by the LLM (Syntax Error).
- **Recovery Logic:** The parser explicitly returns a `Result::Err` containing the AST error node. The Engine catches this error and safely returns a 400 Bad Request to the caller or prompts the LLM for self-correction without crashing the inference loop.
