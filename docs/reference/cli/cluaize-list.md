# `cluaiz list` Command Reference

The `list` command displays all installed models registered in the local workspace node.

---

## 📋 Syntax & Usage

```bash
cluaiz list
```

---

## ⚙️ Output Schema

Outputs a formatted table showing:
* **MODEL ID:** The name/version key (e.g. `bonsai:8b`).
* **TYPE:** Category (e.g. `chat` or `vector`).
* **SIZE:** File size in gigabytes.
* **HASH:** The unique checksum signature.
