# `cluaiz status` Command Reference

The `status` command evaluates active hardware variables and engine layers.

---

## 📋 Syntax & Usage

```bash
cluaiz status
```

---

## ⚙️ Output Details

Displays:
* **System Identifiers:** Active profiles and workspace links.
* **Compute Drivers:** Lists bound dynamic FFI bridges (e.g. CUDA, Metal).
* **RAM & VRAM Maps:** Outlines allocated model layers and available VRAM buffers to trace memory usage.
