# Cluaize CLI Command Reference Manual

This index details every command provided by the `cluaize` command-line binary.

---

## 🚀 Command Index

* ### [`cluaize serve`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-serve.md)
  Launches the background Engine API Daemon + Named Pipe IPC server.
* ### [`cluaize run`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-run.md)
  Pulls and executes a model in interactive TUI or single-pass mode.
* ### [`cluaize pull`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-pull.md)
  Downloads and registers a model into the local secure vault.
* ### [`cluaize list`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-list.md)
  Lists all currently downloaded models in the local vault.
* ### [`cluaize rm`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-rm.md)
  Removes a specified model from local storage.
* ### [`cluaize model`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-model.md)
  Sets the active chat or vector model inside configurations.
* ### [`cluaize brain`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-brain.md)
  Controls the C-FFI database connection to local or remote database instances.
* ### [`cluaize booster`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-booster.md)
  Adjusts performance modes, KV caching, and spec-decoding on system booster profiles.
* ### [`cluaize permission`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-permission.md)
  Manages local node telemetry, firewall strictness, and security variables.
* ### [`cluaize skill`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-skill.md)
  Installs, lists, or clears local cache for WASM-based autonomous agent skills.
* ### [`cluaize calibrate`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-calibrate.md)
  Profiles local hardware constraints to output a tuned SiliconTruth configuration.
* ### [`cluaize benchmark`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-benchmark.md)
  Runs standardized hardware execution tests on selected models.
* ### [`cluaize status`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-status.md)
  Displays hardware health, engine memory allocations, and active FFI drivers.
* ### [`cluaize ps`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-ps.md)
  Shows active processes and neural pipelines running in VRAM.
* ### [`cluaize ingest`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaize/docs/reference/cli/cluaize-ingest.md)
  Ingests local files (PDF, TXT, MD) into semantic database chunks.
