# cluaiz CLI Command Reference Manual

This index details every command provided by the `cluaiz` command-line binary.

---

## 🚀 Command Index

* ### [`cluaiz serve`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-serve.md)
  Launches the background Engine API Daemon + Named Pipe IPC server.
* ### [`cluaiz run`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-run.md)
  Pulls and executes a model in interactive TUI or single-pass mode.
* ### [`cluaiz pull`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-pull.md)
  Downloads and registers a model into the local secure vault.
* ### [`cluaiz list`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-list.md)
  Lists all currently downloaded models in the local vault.
* ### [`cluaiz rm`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-rm.md)
  Removes a specified model from local storage.
* ### [`cluaiz model`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-model.md)
  Sets the active chat or vector model inside configurations.
* ### [`cluaiz brain`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-brain.md)
  Controls the C-FFI database connection to local or remote database instances.
* ### [`cluaiz booster`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-booster.md)
  Adjusts performance modes, KV caching, and spec-decoding on system booster profiles.
* ### [`cluaiz permission`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-permission.md)
  Manages local node telemetry, firewall strictness, and security variables.
* ### [`cluaiz skill`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-skill.md)
  Installs, lists, or clears local cache for WASM-based autonomous agent skills.
* ### [`cluaiz calibrate`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-calibrate.md)
  Profiles local hardware constraints to output a tuned SiliconTruth configuration.
* ### [`cluaiz benchmark`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-benchmark.md)
  Runs standardized hardware execution tests on selected models.
* ### [`cluaiz status`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-status.md)
  Displays hardware health, engine memory allocations, and active FFI drivers.
* ### [`cluaiz ps`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-ps.md)
  Shows active processes and neural pipelines running in VRAM.
* ### [`cluaiz ingest`](file:///c:/Users/Aryan/my/Cluaiz-workspace/Cluaiz-Technologies/cluaiz/docs/reference/cli/cluaiz-ingest.md)
  Ingests local files (PDF, TXT, MD) into semantic database chunks.
