Engine Lifecycle & Models

Pure Brain Mode (LLM OFF) Disabled: Normal mode. Generative AI is active.
Lazy Load Model (On Send) Disabled: Model loads instantly on startup.
Chat Model Primary conversational LLM & Multimodal Chat VLM loaded into memory.
Embedding & Vector Model Unified multimodal dense vector embedding model for semantic retrieval and search.
Document & Ingest Model Specialized document OCR, table extraction, and spatial vision model.
Text-To-Speech (TTS) Model Neural voice synthesis and speech generation model.
Speech-To-Text (STT) Model Automatic speech recognition (ASR) and audio transcription model.

LLM Optimization & Hardware Governance

VRAM Safety Buffer Reserved GPU memory margin to guarantee 0% OOM crashes.
Auto (% Dynamic)
CPU RAM Safety Buffer Reserved System RAM headroom for OS and background apps.
Auto (% Dynamic)
Flash Attention (flash_attn) Forces Flash Attention. Very fast for long contexts.
Smart Memory Management (Context Shifting) System dynamically balances memory consumption and chat history retention.
KV Cache Quantization (type_k / type_v) System decides the best quantization level (F16, Q8_0, Q4_0).
Speculative Decoding (--draft) Accelerates inference using secondary draft models or lookup tables.
Extreme MoE SSD Streaming Zero-RAM out-of-core streaming for MoE models directly from NVMe SSD with DMA staging.
Hybrid Memory Mode (VRAM + RAM) Dynamically combines GPU VRAM and System RAM for larger context windows.
Memory Lock (use_mlock) Locks model weights in RAM/VRAM to prevent OS pagefile swapping and latency spikes.
