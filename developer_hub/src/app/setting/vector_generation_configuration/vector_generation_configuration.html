Vector Generation Configuration

Configure the embedding models used for RAG and semantic search operations.

Hardware & Execution (GGUF)

GPU Layers (n_gpu_layers) Number of layers to offload to the GPU for the GGUF embedding model. -1 offloads all layers.
Batch Size The number of tokens processed simultaneously during embedding generation.

Hardware & Execution (ONNX)

Hardware Offload Choose where to run the ONNX model. The engine will automatically pick the best driver (CUDA, DirectML, ROCm, etc.) if GPU is selected.

Vector Processing (General)

Normalize Vectors Apply L2 normalization to the generated embeddings. Required for cosine similarity search.
Pooling Strategy Method used to aggregate token embeddings into a single sentence vector (Mean is most common).
