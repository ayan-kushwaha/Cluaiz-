Hardware & Execution

GPU Layers (n_gpu_layers) VRAM layer offload count. Use -1 for full VRAM allocation, 0 for host CPU execution.
Context Window Size (n_ctx) Token context window size. Use -1 for maximum native model limit, 0 for dynamic auto sizing based on leftover memory.
No MMAP (no_mmap) Bypasses mmap() file I/O calls. Reads tensor weights directly into physical host RAM.
Override Tensor (override_tensor) Regex tensor placement rules. Forces designated layers (e.g. FFN blocks) to host RAM.
Batch Size (batch_size) Logical prompt evaluation batch length evaluated per step.
UBatch Size (ubatch_size) Physical micro-batch chunk size dispatched per compute kernel launch.
Parallel Sequences (parallel) Maximum concurrent sequence slots allocated in KV cache state.
Speculative Type (spec_type) Speculative decoding strategy (draft-mtp or n-gram) for lookahead proposal.
Speculative Draft Max (spec_draft_n_max) Max sequence depth for speculative draft lookahead verification.

Memory & Hardware Control

Inter-Op Threads (Graph Execution) Thread count for concurrent graph branch operators. Recommended 0 for sequential transformer inference.

Execution Mode ONNX operator execution strategy (ORT_SEQUENTIAL vs ORT_PARALLEL).
GPU Memory Limit Bytes Maximum VRAM allocation limit for ONNX session. 0 specifies unconstrained allocation.
